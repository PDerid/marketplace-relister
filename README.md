# Marketplace Relister

Marketplace Relister helpt je om je eigen zoekertjes opnieuw te plaatsen zonder alle gegevens manueel opnieuw in te vullen.

## Wat doet het?

- Maakt een kopie van de titel, prijs, omschrijving, categorie en foto's van een eigen zoekertje.
- Opent de normale plaatsingsflow van de marketplace.
- Vult de opgeslagen gegevens en foto's voor je in.
- Laat jou alles controleren en de nieuwe advertentie zelf bevestigen.
- Biedt daarna aan om het oorspronkelijke zoekertje te verwijderen.

De extensie voert nooit zelfstandig de definitieve plaatsing, CAPTCHA-, betaal- of promotie-stappen uit. Je houdt altijd de controle en moet elke belangrijke actie zelf bevestigen.

Momenteel is Marketplace Relister gericht op 2dehands. Ondersteuning voor andere marketplaces kan later worden toegevoegd.
